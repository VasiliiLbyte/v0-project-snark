## Карта модулей MVP (реализовано / в работе)

| Модуль | MVP статус | Ключевые маршруты |
|--------|------------|-------------------|
| Портал и дашборд | MVP есть | `/dashboard` |
| Сотрудники и оргструктура | MVP есть | `/contacts`, `/structure`, `/admin/structure-import` |
| Новости | MVP есть | `/news`, `/admin/news` |
| Документы | MVP есть | `/documents` |
| База знаний | MVP есть | `/knowledge`, `/admin/knowledge` |
| Service Desk | MVP есть | `/support`, `/admin/tickets` |
| HR (отпуска) | MVP есть | `/profile`, `/admin/vacations` |
| Задачи | MVP+ | `/tasks`, `/tasks/[id]` |
| Чат | MVP+ | `/chat`, SSE events |
| Протоколы совещаний | MVP | `/protocols`, Python service |
| Админ-зона | MVP | `/admin/**` |
| Бронирование | Заглушка | `/booking` — «в разработке» |
| CRM (сделки) | Не начато | — |
| Заявки (legacy `/requests`) | Заменено | `/support` |

### Роли

- `admin`, `hr_manager`, `employee` — базовые роли
- ACL по модулям; `/admin/**` — только admin | hr_manager
- Security на middleware + дублирование на API

### Сквозные требования

- Даты: отображение `ДД.ММ.ГГГГ`, хранение ISO 8601
- Телефоны: `+7 (XXX) XXX-XX-XX`
- Email: `name@almacorgroup.ru`
- 152-ФЗ: персональные данные только авторизованным; audit log
- Файлы: presigned S3, лимиты 50 МБ / 10 МБ аватар
